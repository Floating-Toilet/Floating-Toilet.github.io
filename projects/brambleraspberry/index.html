Exploring Cluster Computing


Overview

An exploration project to learn about cluster computing

Technical Focus

Linux · Raspberry Pi · Python · Cluster Computing

Hardware

  • 7 Raspberry Pi 2b v1.1
  • Cisco Catalyst 3500

Project Development

While organizing the equipment and cables within the lab I found a large pile of Raspberry Pis I didn't think much of them until the class went down to the Pro Web & Game Design class because Auburn was cutting the class I was in for next year. That day the WGD instructor revealed gCoin, a spinoff off cryptocurrency, and had both classes start mining. Conveniently I had found that stack of Pis the same day, knowing the concept of cluster computing I had envisioned a system where each Pi shared each others resources, this however wouldn't work with my current knowledge (or at all). So I went the simple route of just setting up each Pi individually and let them mine as unique clients.

Is this the way I wanted it to go? No, but I'm sure I'll come across an opportunity to get some hands-on learning on something like Kubernetes or some other cluster mangement software
