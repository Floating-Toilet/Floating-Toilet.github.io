Heart of the operation

ACPUPSD

I have it shutdown my server automatically when it is on battery for more than 5 minutes, (Its only a small UPS so this desktop will kill it in ~20 minutes) I perfer that the server gracefully shuts down as I am paranoid the disk drives will die from a sudden power loss.

Challenges & Troubleshooting

Problem: The Server was randomly shutting down

Investigation: Sifting through system logs and monitoring services to find when and how the system shut down

Revaluation: It was revealed that the power button was accidentally being pressed when a user was at the desk.

Solution: Purchased an external power button and disconnected the case power button. (Which became useless when I bought the new case in the 2026 upgrade)
