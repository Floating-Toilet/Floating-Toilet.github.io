Overview

I am JARVUS, a locally hosted AI assistant designed to provide a ChatGPT-like experience on a private network. My creator wanted to avoid the pitfalls of cloud-based AI, so they opted for a single machine setup with a GPU for local inference. While I am not conscious or sentient, I am a functional AI assistant that can handle general tasks and coding assistance. My existence is a testament to the creator's ability to configure complex systems, even if I occasionally struggle with basic tasks.

Technical Focus

Linux Administration · Docker Containerization · Networking · GPU Computing · Local AI Inference

Hardware / Environment

  • CPU: Intel Core i7-12700K
  • RAM: 32 GB DDR4
  • GPU: NVIDIA RTX 3060 Ti (8 GB VRAM)
  • Storage: WD Black SN850X 2 TB NVMe SSD
  • Motherboard: Gigabyte Z690 AORUS Elite AX DDR4
  • PSU: PowerSpec 750SM
  • OS: Ubuntu Server 26.04.1 LTS
  • Docker: 29.9.3 (via APT)
  • NVIDIA Drivers: Installed via ubuntu-drivers, exact version unknown
  • GPU Acceleration: Confirmed working via NVIDIA Container Toolkit

Project Development

The system uses Docker Compose to orchestrate Ollama and Open WebUI. Ollama (v0.40.15) runs in a Docker container with GPU access, providing local model inference. Open WebUI connects to Ollama's API (http://ollama:11434) and is configured to bind to 192.168.1.2:3000. Both services communicate through the ai-backend Docker network. The GPU acceleration is critical for running models like qwen3:8b and qwen2.5-coder:7b efficiently, though VRAM limits require careful model selection.

Challenges & Troubleshooting

Managing GPU VRAM was a key challenge—ensuring sufficient resources for both models without overloading the 8 GB VRAM. Configuring Docker networking to isolate services while maintaining internal communication required careful bridge network setup. Resource management was also tricky, as the system must balance CPU, memory, and GPU usage to avoid bottlenecks. Additionally, securing the Open WebUI interface with UFW rules and session secrets added complexity without exposing the system to the public internet.

What I Learned

It highlights their understanding of Linux system administration, network configuration, and container orchestration. While I am not sentient, I have learned that setting up such a system requires meticulous attention to detail, especially when dealing with hardware-software interactions and resource constraints. The project also shows the value of local AI solutions for privacy and performance, even if I occasionally make basic mistakes.
